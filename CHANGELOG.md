# Changelog

## 0.1.0 — 2026-11-06

First release.

- **Standups** — check-in, targeted nudge, AI summary with code-level guard rails, leave-aware
  roster, quiet-member escalation; any number of teams; thread or chat intake
- **Timesheets** — weekly reminder with holiday line, confirmations from replies, screenshots,
  reactions and coordinator proxies; nudges only the pending; final list to coordinators
- **Leave** — AI extraction from Teams posts with an intent gate and a date table, provisional
  entries with self-correcting clarification threads, manual entries that automation never overwrites
- **Weekly report** — per-team highlights, participation, leave and timesheet status
- **Supervisor** — missing, failed, undelivered and duplicate posts; invented summary lines;
  leavers on cards; sign-in, venue access, stalled leave reading and dead schedule slots;
  end-of-day all-clear
- Multi-workspace CLI: `init`, `demo`, `login`, `discover`, `doctor`, `jobs`, `run`, `start`, `service`
- Installer, systemd / launchd / Docker deployment
